# nets (Network Module)

[English](README.en.md)

## Overview
This directory contains neural network architecture definitions, including custom convolutional blocks, ResNet34 model definition, Wide ResNet, etc.

## Files
| File | Description |
|------|-------------|
| `blocks.py` | Convolution block definitions |
| `resnet.py` | ResNet34 model definition |
| `resnet50 copy.py` | ResNet50 (reference implementation) |
| `wide_resnet.py` | Wide ResNet definition |
