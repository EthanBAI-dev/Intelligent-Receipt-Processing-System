# nets（ネットワークモジュール）

[**日本語**](README.md)

## 概要
このディレクトリには、ニューラルネットワークのアーキテクチャ定義ファイルが格納されています。カスタム畳み込みブロック、ResNet34 モデル定義、Wide ResNet などが含まれます。

## ファイル一覧
| ファイル | 説明 |
|----------|------|
| `blocks.py` | 畳み込みブロック定義 |
| `resnet.py` | ResNet34 モデル定義 |
| `resnet50 copy.py` | ResNet50 (参考実装) |
| `wide_resnet.py` | Wide ResNet 定義 |
