# マルチレシートコーナー検出システム

[中文](README.md) | [English](README_EN.md)

---

## 1. プロジェクトのコア機能と位置づけ

本プロジェクトは **YOLOv8m-Detect** をベースとしたマルチレシートコーナー検出システムです。**4-in-1 合成画像**から各レシートのバウンディングボックスと4つの角点を高精度に検出し、その後の透視補正とOCR認識のための位置情報基盤を提供します。

**主な用途**：
- 4枚のレシートが含まれる合成画像から、各レシートのバウンディングボックスを検出
- 各レシートの4つの角点（左上、右上、右下、左下）を検出
- 透視補正のための角点座標を提供し、レシートの正面補正を実現
- 本プロジェクトは**基本検出モデル**であり、完全なOCR認識システムに統合されています

## 2. コア技術と実装ロジック

### 技術スタック

| 技術 | 用途 |
|------|------|
| **YOLOv8m-Detect** | レシート枠と角点枠を同時検出する物体検出モデル |
| **PIL / OpenCV** | 画像の透視変換と処理 |
| **NumPy** | 行列演算（ホモグラフィ行列計算） |
| **SAHI** | スライス補助推論（v1/v2 で歴史的に使用） |

### モデル出力（5クラス）

| Class ID | 名称 | 説明 |
|----------|------|------|
| 0 | receipt | レシート全体のバウンディングボックス |
| 1 | corner_tl | 左上角点 |
| 2 | corner_tr | 右上角点 |
| 3 | corner_br | 右下角点 |
| 4 | corner_bl | 左下角点 |

### データ生成ロジック

`train/generate_data.py` は以下の手順で単一レシート画像を合成します：

1. **ソース画像収集** — `train/source_images/` から個別のレシート画像を読み込み
2. **透視変換** — 各レシートに ±12° の 3D 透視変換 + 局所変形を適用
3. **ランダム回転** — 70% の確率で ±6° 回転（データ多様性の向上）
4. **トリミング** — 変換後の空白エッジを自動除去
5. **水平連結** — 4 枚の変換済みレシートを灰色キャンバスに貼り付け（120px 間隔）
6. **ラベル生成** — 各レシートに 5 個のバウンディングボックス（1 receipt + 4 角点）
7. **自動圧縮** — 最長辺を 1280px に圧縮

### 3段階透視補正戦略

`tools/perspective_utils.py` の `rectify_receipt()` は3段階のフォールバックを提供します：

1. **角点法**（優先）— 検出された4つの角点枠の中心を使用した4点透視変換（5項目の検証付き）
2. **OpenCV 輪郭法**（フォールバック）— CLAHE + 適応的閾値処理 + 形態学処理 + 最大四角形フィッティング
3. **元画像返却**（最終フォールバック）

## 3. 開発履歴

### v1 — YOLOv8-Pose キーポイント方式（アーカイブ済み）

- **方式**：YOLOv8-Pose モデル、角点をキーポイントとして回帰
- **データ**：~150 枚の合成訓練画像
- **問題点**：キーポイント回帰の精度が限定的、信頼度出力不可

### v2 — Pose データ拡張版（アーカイブ済み）

- **方式**：v1 と同じ Pose キーポイント方式
- **データ**：~500 枚の合成訓練画像
- **モデル**：`best_2.pt`
- **問題点**：Pose 方式の固有の制限が残存

### v3 — YOLOv8-Detect 角点検出方式（現在の本番バージョン）

- **主要な変更**：角点を Pose キーポイントから**独立した検出対象（Detect ボックス）**に変更
- **利点**：各角点が独立した信頼度を出力、NMS フィルタリング対応、高精度
- **データ**：300 枚の合成訓練画像
- **モデル**：`model/best_v8_300.pt`
- **ステータス**：本番環境で使用、OCR システムに統合済み

### バージョン比較

| バージョン | 方式 | データ量 | 角点方式 | 補正成功率 | 状態 |
|-----------|------|---------|---------|-----------|------|
| v1 | YOLOv8-Pose | ~150 | キーポイント | 低い | アーカイブ |
| v2 | YOLOv8-Pose | ~500 | キーポイント | 低い | アーカイブ |
| **v3** | **YOLOv8-Detect** | **300** | **独立検出ボックス** | **~70% 角点法 + OpenCV フォールバック** | **本番稼働** |

> 過去バージョンは `back up/项目迭代文件/multi_receipt_detection/` にアーカイブされています

## 4. インストールとデプロイ

### 環境要件

- Python >= 3.8
- OS: macOS / Linux / Windows

### ディレクトリ構造

```
multi_receipts detection/
├── train/                           # 訓練パイプライン
│   ├── generate_data.py             #     データ生成スクリプト

│   └── yolo_dataset/                #     生成された合成データセット
│       ├── data.yaml                #     データセット設定ファイル
│       ├── images/train/            #     訓練画像

├── model/                           # モデル重み

├── tools/                           # ツール
```

### インストール手順

```bash
# 1. プロジェクトディレクトリに移動
cd multi_receipts detection/

# 2. 仮想環境の作成（推奨）
python -m venv venv
source venv/bin/activate   # macOS/Linux

# 3. 依存関係のインストール
pip install ultralytics pillow numpy pyyaml opencv-python
```

### クイックスタート

```bash
# 1. サンプルデータの生成（10 枚）
cd train/
python generate_data.py

# 2. 推論評価の実行
cd ..
python evaluate.py                     # 推論統計
python evaluate.py --save              # 推論 + 注釈画像の保存

# 3. モデル訓練（全データセット）
yolo detect train data=train/yolo_dataset/data.yaml \
      model=yolov8m.pt epochs=300 imgsz=1280 batch=8

# 4. 訓練済みモデルで推論
yolo detect predict model=model/best_v8_300.pt \
      source=final_test/ save=True
```

### テスト画像

`final_test/` ディレクトリには、モデル検証用の3枚の実写4-in-1レシート写真が含まれています。
